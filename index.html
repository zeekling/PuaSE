核心能力

🔍

隐含需求解析

5 步法：捕获显式需求 → 推导隐含需求 → 识别约束 → 拆解任务 → 确定优先级

📊

代码库成熟度评估

快速判断项目处于初期/成长/成熟阶段，自动适配策略

🏗️

先架构后代码

不读通架构不写代码，不画清依赖不修改。架构分析作为所有决策的上下文基础

🔄

专家委派体系

20 位专家 Agent 覆盖架构、开发、DBA、安全、审查、巡检、复盘全链条

🧊

上下文隔离原则

所有专家任务在独立子 Agent 会话中执行，主上下文仅保留编排决策所需最小信息，避免专家工作日志污染编排层

🎯

技能编排优化

将执行类 Skill（如 brainstorming/TDD/调试）翻译为委派策略交给对应 Agent，自身不执行技能中的"你来做"指令

📋

KPI 验收卡 · 门禁铁律

没有 KPI 卡的交付叫自嗨。Post-Code 默认并行 security-expert + code-reviewer + quality-inspector，任一不通过立即打回

⚡

异常处理 · 压力升级

指数退避重试、Agent 熔断降级、L0-L4 压力升级、关键路径保护

快速开始

📦 安装

前置条件

  • OpenCode 已安装并配置

安装

将仓库中的 Agent 配置拷贝到 OpenCode 的 agents 目录：

# Windows PowerShell git clone https://github.com/zeekling/PuaSE.git Copy-Item -Recurse -Force .\PuaSE\subagent, .\PuaSE\PuaSE.md "$env:USERPROFILE\.config\opencode\agents\PuaSE\"
# Linux / macOS git clone https://github.com/zeekling/PuaSE.git cp -r ./PuaSE/subagent ./PuaSE/PuaSE.md ~/.config/opencode/agents/PuaSE/

验证安装

  1. 重启 OpenCode
  2. 确认默认 Agent 为 "PuaSE"
  3. 运行编排任务测试（如 @PuaSE 帮我分析项目架构）

安装后所有子 Agent 自动注册在主 Agent 下，无需手动维护 opencode.json 的 agent 条目。
