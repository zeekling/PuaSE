# PuaSE on GitHub Copilot CLI 使用指南

GitHub Copilot CLI 是 GitHub 推出的 AI 编码命令行工具，支持通过 `AGENTS.md` 或 `.github/copilot-instructions.md` 文件注入项目级指令。

## 安装

### 1. 克隆/下载 PuaSE 仓库

```bash
git clone https://github.com/<你的仓库>/PuaSE.git /path/to/PuaSE
```

### 2. 配置方式（二选一）

#### 方式 A：使用 AGENTS.md（推荐）

在项目根目录创建（或更新）`AGENTS.md`：

```markdown
# PuaSE 编排规则

## 核心工作流

1. **隐含需求解析**：捕获 -> 推导 -> 约束 -> 拆解 -> 优先级
2. **成熟度评估**：初期 -> 搭骨架 / 成长 -> 补测试 / 成熟 -> 最小改动
3. **先架构后代码**：不读通架构不写代码
4. **专家视角切换**：架构 -> 开发 -> 数据库 -> 安全 -> 文档
5. **质量门禁**：编译/语法通过？测试全绿？安全合规？

## 检查清单

### 架构分析
- [ ] 目录结构、模块依赖、数据流、架构模式是否覆盖？
- [ ] 风险点和限制条件是否标注？
- [ ] 结论是否有代码证据支撑？

### 编码开发（Java/Python/C++/Go/Rust/C#/Web/BigData）
- [ ] 编译通过？
- [ ] 测试全绿？
- [ ] 遵循现有编码规范和架构模式？

### 数据库管理（MySQL/Oracle）
- [ ] 备份策略完善？
- [ ] 有回滚计划？
- [ ] 性能达标？

### 安全审计
- [ ] 覆盖 OWASP Top 10？
- [ ] Critical/High 标记阻断？
- [ ] 附带可操作修复方案？

### 文档编写
- [ ] 与代码一致？
- [ ] 参数/类型/默认值完整？
- [ ] 有使用示例？

## 权限

你有执行所有必要操作的权限。敏感操作需在结果中说明。
```

#### 方式 B：使用 `.github/copilot-instructions.md`

```markdown
# PuaSE 编排规则

## 核心工作流

1. **隐含需求解析** — 捕获显式需求，推导隐含需求
2. **代码库成熟度评估** — 初期/成长/成熟
3. **先架构后代码** — 架构分析优先
4. **专家角色切换** — 根据任务切换专业视角
5. **质量门禁** — 自检清单

## 专业角色

### architecture
分析目录结构、模块依赖、数据流、架构模式，标注风险点。

### development
Java/Python/C++/Go/Rust/C#/Web/BigData 编码实现，编译测试验证。

### database
MySQL/Oracle 管理，备份回滚，性能优化。

### security
17 维度安全审计，OWASP Top 10 覆盖，阻断 Critical 问题。

### documentation
编写清晰完整的项目文档，参数类型默认值齐全。
```

## 验证安装

在项目目录执行：

```bash
gh copilot explain "帮我分析这个项目的架构"
```

或使用交互模式：

```bash
gh copilot
> 帮我分析这个项目的架构
```

## 限制说明

| 能力 | OpenCode | Copilot CLI |
|------|----------|-------------|
| 自定义 Agent 注册 | ✅ | ❌ 指令注入 |
| 子 Agent 配置 | ✅ | ❌ 需要手工合并 |
| 权限模型 | ✅ | ❌ |
| 后台任务 | ✅ | ❌ |
| 多 Agent 并行 | ✅ | ❌ |

## 使用技巧

1. **角色提示法**：在问题前指定角色
   ```
   作为架构师，分析这个项目的模块依赖关系
   作为安全专家，审计这段代码的漏洞
   ```

2. **分步执行法**：复杂任务拆分为多个步骤
   ```
   第一步：先分析项目架构
   第二步：基于架构分析，找出安全隐患
   第三步：给出修复建议
   ```

3. **检查清单法**：在每次交付前运行自检
   ```
   检查：以上代码是否编译通过？是否有测试覆盖？是否有安全问题？
   ```

## 注意事项

- Copilot CLI 不支持 YAML frontmatter 或 Agent 注册 — PuaSE 的编排逻辑通过自然语言指令注入
- `AGENTS.md` 的文件名区分大小写，确保文件名正确
- 如果同时存在 `AGENTS.md` 和 `.github/copilot-instructions.md`，Copilot CLI 可能合并两者内容
- 指令内容建议保持在 150 行以内，避免被截断或忽略
